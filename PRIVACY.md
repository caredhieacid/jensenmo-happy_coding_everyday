# Privacy

HappyCoding Everyday is a set of written instructions for your AI coding assistant. It does not
collect, store, or send any data.

- It contains no program that runs by itself, no server, no hooks, and no telemetry.
- It makes no network requests of its own.
- It does not ask for or store credentials.

Your code and conversations are handled by the coding assistant you use (for example, Codex) under
that provider's own privacy policy and terms.

Questions: open an issue in this repository, or see [Support](SUPPORT.md).
